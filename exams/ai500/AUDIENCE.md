# AI-500: audience and exam-specific rules

Audience (expert level): expert practitioner who designs, builds and runs
production multi-agent systems on Microsoft Foundry; proficient in Python;
knows Azure compute, network, storage and data services; familiar with
Microsoft Agent Framework, MCP, RAG and LangGraph.

- **Code language:** Python only, no C#/.NET. Commands: `az`, `azd`, `func`,
  `pip`, `git`, GitHub Actions, Bicep.
- **Product names:** Microsoft Foundry (not Azure AI Foundry / AI Studio),
  Microsoft Entra ID (not Azure AD), Foundry Agent Service, Microsoft Agent
  Framework, Azure AI Search, Azure AI Content Safety, Azure API Management.
- **Open-source frameworks** (LangGraph, LangChain, A2A, MCP, Hugging Face):
  test well-established concepts only, and use the closest Learn page as ref.
